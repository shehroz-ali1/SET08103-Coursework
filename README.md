# SET08103 Software Engineering Methods: World Population Reporting System

## Overview
This application provides a comprehensive reporting system for the World database, generating population reports for countries, cities, capital cities, top populated areas, and urban/rural breakdowns as specified by organisational requirements.

## Requirements Met Table

| ID | Requirement | Status | Screenshot Proof |
|---|---|---|---|
| 1 | All the countries in the world organised by largest population to smallest. | Done | 
| 2 | All the cities in the world organised by largest population to smallest. | Done | 
| 3 | All the capital cities in the world organised by largest population to smallest. | Done | 
| 4 | The top N populated cities in the world where N is provided by the user. | Done | 
| 5 | The population of people, people living in cities, and not in cities in each country. | Done | 
| 6 | The population of the world, continents, regions, and countries. | Done |
